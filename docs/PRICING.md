# Ceník - Metro Praha Informační Displej

## 📋 Přehled produktu

**Metro Praha Displej** je profesionální informační systém pro zobrazování real-time dat pražské integrované dopravy. Systém je optimalizován pro průmyslové displeje s rozlišením 4096×607px.
